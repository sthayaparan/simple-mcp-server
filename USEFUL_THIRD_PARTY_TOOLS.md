# Useful Third-Party Tools

## MCPJam Inspector

Developer tool for inspecting and testing MCP Server tools.

```
npx @mcpjam/inspector@latest
```

To inspect the Member MCP Server, start the server (`scripts\start.ps1` or `./scripts/start.sh`), then in the inspector connect using Streamable HTTP to `http://127.0.0.1:8000/mcp`.
